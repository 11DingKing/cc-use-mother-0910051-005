# 企业双积分核算与交易服务

本项目是使用 Python、FastAPI 与 SQLite 实现的服务端应用，覆盖企业、车型、年度核算、订单撮合、交易结转和统计。它可在单个 Linux 应用容器内完成安装、测试、编译和接口验收，不依赖浏览器、外部数据库、缓存、消息队列或额外运行服务。

## 核算输入版本与封账机制

为保证已公布积分可解释、可追溯，系统在年度核算链路上提供：

- **核算输入版本**：企业每次提交（含补交的产量/能耗凭证）形成一个完整、不可变的输入版本
  （`input_versions` + 逐车型明细 + 限值标准快照），带内容哈希，内容相同的重复提交不产生新版本；
  两个版本可逐车型逐字段比较（`GET /api/v1/input-versions/{id}/diff`）。
- **封账**：监管确认后调用 `POST /api/v1/seals/` 冻结当期各企业采用的输入版本、限值标准、
  逐车型结果与企业汇总。封账后当期车型数据、积分记录、批量核算与重新封账一律被拒绝，
  不能再悄悄改写已公布结论。
- **重开重算**：确需调整须凭重开决定 `POST /api/v1/reopen-decisions/`，必须记录理由、批准人、
  批准权限和受影响企业，并指定重算所依据的输入版本。重算生成新封账，旧封账标记为 `reopened`
  并完整保留，同时在差异表中给出逐车型（限值、实际电耗、产量、单车积分、车型总积分）与
  企业汇总（正/负/净积分、缺口、结余）各积分项的新值、旧值与差额。
- **幂等与失败隔离**：同一重开决定单号重复执行不再生成新版本或新封账；批量重算中单个企业失败时，
  新封账保留其原封账结果与原版本引用，并记录失败原因。
- **下游留痕**：年度汇总、交易挂单、成交记录、跨年度结转均记录所依据的封账；封账后年度汇总的
  正/负/净积分口径冻结，交易与结转只滚动买卖、结转与最终可用额字段，可售额度始终取自当前生效封账。

## 安装

```bash
python3 -m pip install -r requirements.txt -r requirements-dev.txt
```

## 测试

```bash
python3 -m pytest -q
```

其中 `test_dual_credit_integration.py` 覆盖原有核算全链路，`test_version_seal_integration.py`
覆盖输入版本、封账、重开重算（含幂等、单企业失败隔离与差异）。

## 编译

```bash
python3 -m compileall -q .
```

## 接口验收

```bash
python3 -c "from app.main import app; assert len(app.routes) > 5; print(len(app.routes))"
```

## 启动

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
